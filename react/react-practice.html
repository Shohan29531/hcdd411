You know Task 2 is done when

Common mistake

Writing count = count + 1 directly. That will not trigger a re-render. Always use the setter: setCount(count + 1).

Task 3 · Hints

Three specific patterns to remember

1 — Controlled input
Pattern: controlled input
// The input value is always the state value.
// onChange updates the state, which updates the input.
// This is called a "controlled" input.
<input
  value={search}
  onChange={(e) => setSearch(e.target.value)}
  placeholder="Search students"
/>
2 — Filtering
Pattern: filter by search text
// .filter() returns a new array — it does not change students.
const filtered = students.filter((s) =>
  s.name.toLowerCase().includes(search.toLowerCase())
)
3 — Conditional render
Pattern: show panel only when selected is not null
// {selected && ...} renders nothing when selected is null.
// It renders the JSX when selected is a student object.
{selected && (
  <p>Selected: {selected.name} — {selected.major}</p>
)}
You know Task 3 is done when

Typing "i" in the search box shows only students whose name contains the letter "i". Clicking any list item updates the selected panel below. Clearing the input restores the full list.
